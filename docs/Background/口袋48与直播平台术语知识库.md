## 一、口袋48 APP 简介

**口袋48** 是 SNH48 GROUP 的官方 APP（上海丝芭文化传媒集团开发），2015年8月18日上线，Android/iOS 双平台。

核心定位：粉丝与偶像互动的官方平台。因公司规定禁止偶像私下与粉丝通过微信/微博私信等方式接触，所有官方互动渠道集中在口袋48上。

### 主要功能板块

| 功能 | 说明 |
|------|------|
| **成员直播** | 成员在自己的「房间」开直播，粉丝可观看、发弹幕、送礼物 |
| **聚聚房间** | 粉丝之间聊天互动的群组空间（Lv3以上可创建） |
| **公演直播/回放** | 剧场公演的在线直播及历史回放 |
| **翻牌** | 付费功能，粉丝可向成员发送私信提问，成员选择回复 |
| **云握手会** | 线上虚拟握手会活动 |
| **投票** | 总决选、金曲大赏等活动的投票入口 |
| **视频** | 正片、剪辑、花絮等视频内容 |
| **行程/演出信息** | 成员演出安排、公开课、生日公演、签售会等 |

## 二、口袋48 虚拟经济系统

口袋48 有完整的虚拟货币和激励体系，LLM 需要理解这些术语，以免字面误解。

### 货币体系

| 名称 | 获取方式 | 用途 |
|:----:|---------|------|
| **鸡腿** 🍗 | 充值购买（**10鸡腿 = 1元人民币**） | 作为礼物送给成员 / 在应援商城兑换周边商品 |
| **鸡翅** 🦅 | 通过签到、互动等日常任务获得（每日有获取上限） | 兑换鸡腿、礼物道具、异业权益 |
| **丝瓜币** 🥒 | SNH48 官方平台通用积分 | 商城购物等 |
| **成长值** 📈 | 通过互动累计 | 提升用户等级，等级高则鸡翅获取更多、福利更好 |
| **徽章** 🏅 | 达到一定等级或完成特定成就获得 | 展示在昵称旁边，是粉丝身份的象征 |

### 关键理解

> **「谢谢xxx送的巧克力 / 冰美式 / 秋天的奶茶」**
>
> 这不是真实食物/饮料。这是**口袋48直播间的虚拟礼物**，每个礼物对应不同金额的虚拟货币（鸡腿）。主播说"谢谢xxx送的巧克力"意思是粉丝在直播间花钱购买了巧克力这个虚拟礼物送给她。
>
> 💰 **兑换比例：10鸡腿 = 1元人民币**。即一个礼物标价多少鸡腿，除以10就是其人民币价值。
> 例如：用爱发电标价19,999鸡腿 ≈ 2,000元人民币；玫瑰花标价20鸡腿 = 2元人民币。

### 口袋48 礼物系统详解

口袋48的礼物分为两大分类（顶部导航）：**热门**、**荧光棒**。

- **热门**：包含常驻礼物和限时活动礼物，是直播中最常被送的礼物
- **荧光棒**：各队伍不同颜色的荧光棒，粉丝可在直播中赠送为偶像应援

> ℹ️ 顶部导航还有一个 **「口袋」** 标签，但这**不是礼物分类**。每个用户有一个自己的「口袋」，里面存放的是用户**已经拥有**的礼物库存。有些用户可能通过活动获得了特殊礼物存放在口袋里，而普通用户的口袋可能是空的。

部分礼物右上角带 **「连」** 字标识，表示该礼物支持**连击/连续赠送**（一次性赠送多个）。

## 三、直播互动常用术语

### 打赏与排行

| 术语 | 实际含义 | LLM 易误解 |
|:----:|---------|:---------:|
| **榜一 / 榜二 / 榜三** | 打赏金额排名前三的观众 | ❌ 以为是排行榜/榜单 |
| **刷礼物** | 连续或不间断地送虚拟礼物 | ❌ 以为是刷某种真实物品 |
| **礼物结算 / 提现** | 主播收到的虚拟礼物折算成真实货币（平台抽成后提现） | |

### 直播互动

| 术语 | 实际含义 |
|:----:|---------|
| **弹幕** | 观众在直播间发送的滚动评论（scrolling comments），不是真的"炮弹幕" |
| **PK** | 两个主播在规定时间内比赛收礼物，输的有惩罚 |
| **连麦** | 两个主播视频/音频连线，观众可以同时看到两人 |
| **点歌** | 观众在直播间要求主播唱歌 |
| **读弹幕** | 主播把弹幕内容念出来并回应 |
| **念ID** | 主播念送礼观众的昵称表示感谢 |

### 粉丝相关

| 术语 | 实际含义 |
|:----:|---------|
| **白嫖 / 白嫖党** | 只看直播/内容但不花钱的粉丝（中性/略带调侃） |
| **金瓜** | 花钱多的粉丝 |
| **钻瓜** | 花钱非常多的粉丝 |
| **应援会** | 粉丝自发组织的后援团体 |

## 五、直播内容理解要点（LLM 特别注意）

### 1. 主播「转述」与「自述」的区分

在直播中，主播经常会：
- **念弹幕**：「这里有人说……」「有弹幕问……」
- **转述观众意见**：「有人说我今天的妆不好看」
- **回应弹幕**：「没有啊，我没说过那个」

LLM 需要根据上下文判断：如果主播的话和弹幕内容相似、或者出现在弹幕之后，很可能是主播在回应/转述弹幕，而不是主播自己的表达。

### 2. 直播中的玩笑与夸张

直播是娱乐性质的互动，主播经常：
- 开玩笑、玩梗
- 夸张表达（如「要死了」「气死了」是情绪宣泄，不是真实状态）
- 和弹幕互动玩梗（如粉丝说"45岁"，主播顺接这个梗）

### 3. 圈内文化

- 粉丝之间的调侃、黑话、圈内梗（如"黑户口"指宠物没有正规手续）不应被理解为恶意
- 主播和粉丝之间的互怼也是一种互动文化，不代表真实的负面关系

### 4. 关于"负面"信息的判断

- 主播说「我今天好烦」「气死了」→ 正常情绪表达
- 主播吐槽宠物/家人/朋友 → 日常互动，不是恶意攻击
- 粉丝弹幕开玩笑 → 需要理解圈内语境，字面判断会误拦

## 六、资料参考来源与可信度分级

> 📊 **可信度等级说明：**
> - **★★★★★** — 官方APP实拍截图，100%准确（如用户截图的礼物列表及价格）
> - **★★★★☆** — 官方文档/公告，基本准确（如APP官方介绍、用户协议）
> - **★★★☆☆** — 权威第三方整理，可能存在遗漏（如百科词条）
> - **★★☆☆☆** — 社区/粉丝分享，需交叉验证（如知乎、豆瓣、贴吧讨论）
> - **★☆☆☆☆** — 行业通用知识，口袋48未必完全套用（如通用直播平台术语）
